# WARA showcase

Competition presentation website for automated scientific discovery in wireless optimization.

**Authors:** Yuan Guo, Yilong Chen, Chao Hu, Zixiang Ren, and Xianghao Yu.

Yuan Guo, Yilong Chen, and Chao Hu: The Chinese University of Hong Kong, Shenzhen.

Zixiang Ren: Department of Electrical and Computer Engineering, National University of Singapore, Singapore.

Standalone static website: video, English narration and captions, architecture, and reported evaluation. This repository is separate from the research code repository.

Publish with GitHub Pages using the main branch and root folder.

Xianghao Yu: City University of Hong Kong, Hong Kong, China.
